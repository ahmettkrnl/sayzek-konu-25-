# sayzek-konu-25-
AI-Powered Network Anomaly Detection and LLM-Assisted Security Event Analysis — Research Proposal
# Yapay Zekâ Destekli Ağ Anomali ve Tehdit Tespit Sistemi //

SAYZEK 2026–2027 | Başvuru

## Durum:
Araştırma ve tasarım aşamasındadır. Yazılım geliştirme ve deneysel çalışmalar henüz başlamamıştır.

## Proje Amacı:
Ağ trafiği ve sistem loglarında anomali tespiti, denetimli ve denetimsiz modellerin karşılaştırılması ve LLM destekli kanıta dayalı Türkçe olay değerlendirmesi geliştirmek.

## Planlanan Yöntemler:
- Isolation Forest
- Random Forest / XGBoost
- Zaman pencereli davranış analizi
- Kanıt temelli Türkçe LLM olay raporlaması

## Planlanan Veri Setleri:
CICIDS2017, UNSW-NB15 ve HDFS_v1.

## Önemli Not Kısmı:
Bu depo mevcut aşamada proje dokümantasyonunu içermektedir. Henüz çalışan bir prototip veya deney sonucu sunulmamaktadır.
